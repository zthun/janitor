# Lint Janitor Config

This is a shared configuration for janitor-lint that contains all of the zthun
scoped shared configurations.

## Getting Started

```sh
# NPM
npm install @zthun/janitor-lint @zthun/janitor-lint-config --save-dev
# Yarn
yarn add @zthun/janitor-lint @zthun/janitor-lint-config --dev
```
